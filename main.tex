\frametitle{Comment diviser par 7 facilement ?}

Il faut se rappeler que $ 1/7 = 0,14228571428857\cdots = 0,\overline{142857}$
\\[0.3em]
La valeur décimale présente une période de 6 chiffres, or $142857$ a une propriété fascinante : c'est 
un nombre \textbf{multi-cyclique}

\begin{multicols}{2}
\begin{itemize}
    \item 142857 x 1 = 142857
    \item 142857 x 2 = 285714
    \item 142857 x 3 = 4285714
    \columnbreak
    \item 142857 x 4 = 571428
    \item 142857 x 5 = 714285
    \item 142857 x 6 = 857142
\end{itemize}
\end{multicols}
Les multiples de 142857 s'écrivent avec les mêmes chiffres, dans le même ordre, à une permutation circulaire
près. 
\\[0.3em]
Il suffit de se rappelerl'ordre des chiffres de 142857, soit 1, 2, 4, 5, 7 8 pour savoir calculer toutes les
valeurs de $1/7$ à $6/7$.
\\[0.3em]
Ainsi $5/7 = 0,\overline{714285}$
\\[0.3em]
A titre d'exemple $22/7= 21/7 + 1/7 = 3 + 1/7 =  3,\overline{142857}$, c'est une approximation de $\pi$
utilisée pendant du temps des pharaons. 
\end{frame}
